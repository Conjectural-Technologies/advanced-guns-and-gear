# Advanced Guns & Gear

Modern firearms, gear and an automated Inventor's Schematics system for D&D 5e in Foundry VTT v14.

**Requirements:** Foundry VTT v14, the D&D 5e system 6.0.6 or newer, and the **Advanced Activities** module.

## Installation

In Foundry's **Add-on Modules** tab choose **Install Module** and paste this manifest URL:

```
https://github.com/Conjectural-Technologies/advanced-guns-and-gear/releases/latest/download/module.json
```

## Features

### Modern weapons
Eight modern weapons are registered with D&D 5e and linked to items in this module's Items compendium. Each uses **martial** weapon proficiency.

- Antimatter rifle
- Automatic rifle
- Hunting rifle
- Laser pistol
- Laser rifle
- Revolver
- Semiautomatic pistol
- Shotgun

### Inventor's Schematics
An automated way to turn a magic item into a schematic an Inventor can build.

- **From the compendium:** right-click an item in any Item compendium and choose **Create Inventor's Schematic**. The schematic goes to your assigned character, or into the Items sidebar if you can create items. Users without either get a warning.
- **From advancement:** when an Inventor's item plan advancement is added to a character, the D&D 5e Compendium Browser opens, already filtered to the right rarity. Pick the item to embed in the schematic.
- **Eligible items:** the source must be a physical, non-cursed, magic **wondrous** item of **common, uncommon or rare** rarity. Anything else is rejected with a clear warning.
- **What gets created:** a copy of the schematic template for that rarity, renamed after the source item, with the item embedded in the description and a private active effect that carries the item as a rider.
- Adds an **Inventor's Schematic** class feature type and enchantment type to D&D 5e.

### Spell lists
Spell list pages are registered for eight classes: Inventor, Alchemist, Armorer, Explorer, Gunner, Mechanist, Engineer and Reanimator.

### Compendium content
Five compendium packs are provided in an **Advanced Guns & Gear** folder, for items, actors, journals, active effects and macros. Players have Observer access and assistants have Owner access. The macros pack may be empty.

### Icons
About 100 bundled SVG icons cover weapons, armour and shields, tools, magic and effects, conditions, movement, creatures and vehicles.
